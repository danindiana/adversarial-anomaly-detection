# Persistent Nonhuman Cohabitation v1.0.0

A **hypothetical model-comparison** package; not evidence that any extraterrestrial or cryptoterrestrial intelligence is on Earth.

## Contents

- `Cohabitation_Adversarial_Detection_v1.0.0.md` — consolidated scientific note, assumptions, caveats, references, models, and numerical results.
- `verify_models.py` — deterministic replication of the calculations and assertions.
- `results.json` — high-precision output from the script.
- `adversarial_results.csv` — summary of optimized hider policies.
- `requirements.txt` — Python runtime requirements.

## Running

```bash
python -m pip install -r requirements.txt
python verify_models.py --output-dir .
```

All priors, detection costs, sample observations, and resident populations in these examples are illustrative assumptions. The script does not read real-world UAP or genomic data. It is not a test of alien existence.
